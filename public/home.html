🎤 Commandes Vocales

Dites "GeNot" suivi de l'une de ces commandes :

Ouvrir un cours

"ouvre le cours de Python"
"entre dans Langage C"
"affiche le module de Maths"
"je veux voir le cours d'Algorithmique"
"emmène moi dans le cours de Réseau"

Variantes : ouvre, affiche, montre, entre dans, va dans, lance, démarre, accède à, dirige moi vers, conduis moi à...

Défiler vers le bas

"défile" (200px)
"descendre 300"
"plus bas"
"avance un peu" (150px)
"scroll beaucoup" (500px)

Variantes : défile, descends, avance, continue, scroll, plus bas, vers le bas...

Défiler vers le haut

"monte" (200px)
"remonte 150"
"plus haut"
"recule un peu"

Variantes : monte, remonte, haut, plus haut, recule, reviens...

"accueil"

Aller tout en bas

"pied de page"
"bas de la page"

Ajouter un cours

Navigation

"paramètres" / "config"
"corbeille" / "poubelle"
"déconnecte" / "quitter"
"aide" / "que puis-je faire"

Astuce : Vous pouvez dire les nombres en chiffres ("300") ou en lettres ("trois cents", "beaucoup"). Si aucun nombre n'est précisé, le défilement est de 200px par défaut.
